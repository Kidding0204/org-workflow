# Sprint 单栏项目与阶段管理

用户已确认本方案并授权实施。

## 目的与范围

在既有 Sprint 单栏中浏览项目／阶段的状态和进度并调整状态。位置为随时之后、今日已完成
之前；明日同样展示，但不增加完成栏。双栏继续保留原有项目树、归类和安排，不重复增加摘要。

## 选择与取舍

已选择 Area 分组、项目与阶段直接逐行显示的紧凑表；相较单独详情页可同时比较，相较看板
保留阶段层级且占用较少空间。顺序为状态、项目／阶段、进度，复用 org-modern TODO 与 cookie
样式。不增加筛选、时长、百分比、任务行或新视图。

## 数据与交互

项目为一级带状态标题，阶段为二级标题，任务为三级及细分。所有状态项目与阶段均可见，
普通阶段无状态时留空。统计普通叶任务，排除 QA 整个子树和习惯；项目合计任务而非平均阶段
百分比，阶段只统计自身子树；零任务显示破折号。摘要去掉源标题已有 cookie，避免重复；
仅显示统计，不写入源文件、ID、Org cookie 或 SQLite。

状态 t／点击状态复用项目 API。TAB 保留 Agenda，在另一个窗口显示原文并展开对应子树；
Enter 在当前窗口访问原文，使用原生 Org Agenda 命令。双栏树 TAB 仍为折叠。
