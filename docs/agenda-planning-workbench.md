# Sprint 安排工作台

[文档入口](README.md)（文中的默认快捷键需设置 `org-workflow-install-default-bindings` 为 t） · [任务与历史模型](workflow-architecture.md)

Sprint 用于挑选、安排和检查任务；Workflow 与 Focus Timer 管理当前任务和执行。
普通 Sprint 保持单栏，双栏安排使用独立入口，窗口变宽不会自动拆分。

## 打开与布局

- `C-c o m a` 或 `M-x org-workflow-open-agenda`：单栏 Sprint。
  显示今天／明天安排、习惯、全部日期未处理收集项和完成回顾。
- `M-x org-workflow-agenda-open-workbench`、Agenda commands 的 `s` 或菜单 `a c`：
  独立「Sprint 工作台」tab。左侧显示安排，右侧显示待安排任务；各自滚动，同步刷新。
- 右侧 tab-line 切换全部或一级标题分组，保留源文件与标题顺序。
  同名分组仍按实际标题身份区分。`q` 或关闭工作台 tab 返回原编辑工作区。
- 今天视图包括逾期执行队列；明天视图只显示明天的安排。
  习惯和完成回顾只在今天视图显示。未来七天区当前不展示。

## 键盘操作

下表是 Sprint 的直接按键；普通 Agenda 保留自身绑定。`?` 显示当前帮助，
绑定被其他模式覆盖时可用 `C-h k` 核对。小写 `j/k` 导航，大写 `J/K` 重排。

| 按键 | 操作 |
| --- | --- |
| `u / i / o` | 安排到当前目标日的上午／下午／晚上 |
| `y` | 同步切换今天／明天视图和安排目标日 |
| `R` | 按任务标签推荐时段 |
| `m / r` | 延至明天／退出安排，保留时段 |
| `U` | 撤销上次明确安排，保留 CLOCK、正文和历史事件 |
| `p` | 创建明日承诺草案，或撤回当前承诺 |
| `SPC / M` | 标记／取消当前项；清除选择 |
| `K / J` | 同一显示日期、同一时段内上移／下移 |
| `j / k / RET` | 下一条／上一条／访问源条目 |
| `I` | 在所在时段新增任务，或在习惯栏新增习惯 |
| `W / E / N` | 周目标／明日开工提示／任务续接提示 |
| `a / ?` | 筛选与视图菜单／按键帮助 |

时段使用原生 Org priority A/B/C；它是安排意图，Workflow 仍按时间累积开放并在空栈时回退。
时段标题仅在存在直接 Effort 时显示预计合计；不重复计算父任务估时，不自动设置容量上限。

## 待安排范围与筛选

默认范围是直接父标题处于 `DIVE` 的未安排 TODO 叶子；不通过中间标题继承范围，
DIVE 叶子自身也不是当前范围候选。`a w` 切换到全部 project/area 范围。
两种范围都排除 HOLD 子树、已安排任务、习惯、非叶子和范围外文件。
范围切换不修改 DIVE 或执行状态。自动开放相邻组见 [DIVE 指南](dive-and-daily-attempts.md)。

`a t/f/d/p` 筛选 @tiny、@flow、@deep 和承诺，`a 0` 清除筛选。
双栏同步筛选，项目分组只过滤右栏。日期、分组、筛选变化清除相关选择。
时段预计负荷仍按完整安排统计；筛选不改源文件。

有批量选择时，日期与时段安排作用于整组；选日期只询问一次。
成功后清除选择并刷新，事务失败回滚该批修改。排序前须清除筛选和批量选择，避免跨过隐藏任务。

## 持久排序、承诺与日期

排序只写一个 `WORKFLOW_ORDER`，例如 `A/0` 表示上午、序号 0。
未完成任务跨日保留相对顺序，换时段后不应用原时段排序；新增任务排在已排序任务之后。
排序可以跨父标题，源文件标题位置不移动。已明确选择或正在执行的目标不随重排切换。

安排明天会创建数据库承诺草案；任务只保存 `WORKFLOW_COMMITMENT_ID`。
界面中的 promise 从数据库事实生成，不写回标签。今日临时加入的是可选任务。
创建时间、承诺日期不镜像到任务属性，不累计延期次数，也不生成原定日期注释。
已生效责任的历史不因改期、HOLD 或撤回而删除；详见 [任务与历史模型](workflow-architecture.md)。

## 新增与收集项

在时段标题、空时段提示或任务行按 `I` 输入单行标题，任务进入目标日期所属周的收集箱，
带对应日期和 A/B/C 时段；习惯栏调用现有 habit 创建命令。
当前和未来周日志保留在 Agenda 中，过去周从普通 Agenda 列表移除。
旧周收集项仍可通过回顾处理和安排，无需扩大普通 Agenda 文件列表。

单栏收集箱按收集日期排列全部积压，已安排、已完成、HOLD、习惯不重复列入，
嵌套内容随所属收集项处理。`C-c o i` 打开归类；成功后刷新原条目，不复制原文。
周日志、捕获与完成回顾见 [周日志与收集箱](daily-journal-inbox.md)。

## 鼠标

- 单击选择；Ctrl 单击增减；Shift 单击选择当前栏可见范围。切换栏会清除另一栏选择。
- 双击访问源条目；双栏工作台返回原编辑 tab。中键只安排点击项到今天并清除旧选择。
- 右键保留当前已选整组；未选项先单选。习惯和完成回顾使用各自适用的操作。
- 从待安排、收集箱或安排任务拖到时段，落点元数据决定日期与时段；移动超过 8 像素才开始拖动。
  选中项拖动整组，未选项只拖单项；近窗格边缘自动滚动。
- `Esc` 或 `C-g` 取消。无效区域不改安排；同日同时段跳过修改。
  成功拖放可用 `U` 整体撤销；不支持拖回取消安排、拖动排序或习惯拖放。

原生 marker、Agenda 类型和操作元数据保持完整。鼠标模式只在 Sprint 生效，
不接管普通 Agenda 或 Org 源文件。当前没有时段容量预算或自动切换日期／tab。
