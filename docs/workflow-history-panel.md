# Workflow 历史面板

[文档入口](README.md)（文中的默认快捷键需设置 `org-workflow-install-default-bindings` 为 t） · [任务与历史模型](workflow-architecture.md)

`M-x org-workflow-history-panel` 打开原生 vui 历史工作台，直接读取当前历史后端；无需生成网页 JSON。面板仅浏览已结算历史，不编辑任务、CLOCK、周日志或历史事实。

## 双栏 tab

`M-x org-workflow-history-panel` 在图形 Emacs 中新建“Workflow 历史”tab；也可直接使用 `M-x org-workflow-history-workbench`。左栏是当前选中月份的日期热力图及所在周的分类投入横条，右栏是当天真实详情。两栏读取当前历史后端，共享日期选择和刷新缓存；已删除固定示例及 preview 命令。

原 tab 的窗口保留；从任一栏按 `q` 或关闭这个 tab，清理两栏并返回原工作区。每次调用命令新建独立历史 tab。窗口足够分屏时并排展示，不足 80 列时使用单栏，通过“日详情 →”和“← 月历”切换。历史两栏隐藏各自重复的 buffer-line，顶部工作台 tab 保留，其他 buffer 的列表不受影响。`b` 回到月历，`RET` 激活所在控件，非控件处进入详情。

## 原单栏追踪入口

`M-x org-workflow-history-tracking` 打开原来的单栏追踪面板：完整历史热力图、分类投入趋势与日详情放在同一 buffer 中，可向下滚动浏览。图形 Emacs 也可使用，不自动创建工作台 tab。数据与双栏共用同一只读后端。

## 操作

| 操作 | 按键或控件 |
|---|---|
| 选择任意日期，包括 missing 日 | `d`，或日期控件后 `RET`，在补全列表选择 |
| 上个月／下个月 | 月历标题下的“← 上个月” / “下个月 →”；覆盖边界禁用，日期尽量保留同一天并裁到有效范围 |
| 前一天／后一天 | `p` / `n`；到范围端点后保持不变 |
| 切换控件／激活 | `TAB` / `S-TAB` / `RET` |
| 刷新当前后端 | `g`，或“刷新历史” |
| 关闭面板 | `q`，或“关闭面板” |
| 浏览较长内容 | Evil 的 `j` / `k`、翻页键，或滚轮 |
| 改变字号 | `M-x text-scale-adjust` |

上述控件在当前 Evil normal、motion 和 emacs 状态可用；从 visual 状态先按 `ESC` 返回 normal，再操作面板。鼠标点击热力格或趋势图内日期列，使用与键盘相同的缓存日期选择路径。日期控件和图表选中标记保持一致，分类分钟数在下方日详情中展示。图表上的滚轮沿用普通区域的鼠标绑定，包括已配置的修饰键滚轮操作。

## 图表语义

月历按周一至周日排列，显示选中月份中有历史覆盖的日期。五级颜色仅依据 `focusTotalMinutes`：0、1–24、25–49、50–89、90+ 分钟。missing 使用 ×，范围外日期不可选。选中日有独立轮廓，投入色阶保留。用 `d` 选择任何历史日期，包括其他月份；`n` / `p` 跨月时同步切换月历。

每日横条展示选中日所在周的承诺、可选和习惯投入，各分类直接采用历史字段。长度按本周已知分类投入的最大合计缩放；总分钟标签保留后端总投入，不推算缺少的习惯工时。旧习惯字段未知时显示 ?，missing 显示缺失，不画零值条。鼠标点击月历日期或横条日期行，同步更新右栏。

窗口大小、字号和主题改变时重绘缓存，不重新读取或结算历史。刷新保留范围内仍有效的选中日期；读取失败显示“未更新”，保留上次月历、横条和详情，按 `g` 重试。终端 Emacs 使用原文字面板与日期选择入口。

## 验证边界

图形行为需要在实际图形 Emacs 中验收，包括中文排版、鼠标、键盘、字号和主题。
